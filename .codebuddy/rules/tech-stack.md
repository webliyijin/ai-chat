# React 19 + Ant Design (antd) + Ant Design X 技术栈规范

## 前端技术栈
- **框架**: React 19.x
- **UI 组件库**: Ant Design (antd) 5.x
- **AI 组件库**: Ant Design X (antd-x) 1.x
- **构建工具**: Vite 5.x / Webpack 5.x
- **语言**: TypeScript 5.x (严格模式)
- **状态管理**: Zustand / dva
- **路由**: React Router 6.x
- **HTTP 客户端**: Axios 或 fetch + 统一拦截器
- **样式方案**: CSS Modules / Tailwind CSS / styled-components
- **包管理**: npm
